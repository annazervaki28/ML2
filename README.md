# ML2
Deep learning and clustering pipeline for image data, developed for the Machine Learning course at the University of Macedonia
# Dimensionality Reduction and Clustering on Fashion-MNIST

## Description
This project presents a comparative evaluation of various Dimensionality Reduction techniques (PCA, Truncated SVD, Stacked Autoencoders) combined with Clustering algorithms (MiniBatchKMeans, GMM, DBSCAN) on the Fashion-MNIST dataset. 

Developed for the Machine Learning course at the University of Macedonia.

## Repository Structure
* `ML-2.pdf`: The technical report detailing the methodology, experiments, and results.
* `ml2.py`: The Python source code for data preprocessing, model training, and evaluation.

## Technologies Used
* Python
* TensorFlow / Keras
* Scikit-Learn
* Pandas / NumPy
* Matplotlib / Seaborn
